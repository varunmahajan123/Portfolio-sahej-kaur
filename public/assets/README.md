# Where your images go

1. **Your photo** → save it as `sahej.jpg` in THIS folder (`public/assets/sahej.jpg`).
   A 4:5 portrait crop around 800×1000px works best. The site shows it top-cropped.

2. **Work samples** → drop them in `work/` as `work-1.jpg` through `work-8.jpg`.
   Which number maps to which card (and how to retitle them) is defined in
   `src/components/Work.jsx` — edit the `projects` array there.

Use JPG or WebP, keep each file under ~300 KB for fast mobile load.
Until an image exists, cards show an elegant purple placeholder automatically.
